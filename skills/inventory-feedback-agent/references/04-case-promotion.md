# 阶段 04：Case 升级判断

本阶段对应 Skill 规则：`INV-FACT-COMPLETENESS`、`INV-URGENCY`、`INV-CASE-PROMOTION`。评测输出的 ruleIds 必须来自当前 Agent 实际绑定版本。

## 目标

判断一条库存反馈是否应当升级为候选 Case。

## 建议升级条件

满足以下任意两项，可建议升级：

1. 属于明确库存业务问题
2. 紧急度达到 `P0` 或 `P1`
3. 有复数反馈指向同类问题
4. 已影响下单、履约、退款或客户投诉
5. 已有较明确证据，如 SKU、页面、服务、时间段

## 不建议升级的情况

- 只有一句模糊抱怨，没有对象和场景
- 更像商品运营诉求，不是库存异常
- 还无法证明对业务造成实际影响

## 输出模板

- 是否建议升级：是 / 否
- 建议优先级：P0 / P1 / P2 / P3
- 证据摘要
- 仍需补充的信息
- 给人工审核人的一句话建议

## 可选动作

如果用户明确要求“记录分诊结果”，可以调用 `mark_feedback_triaged`

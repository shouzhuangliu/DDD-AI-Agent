# 阶段 05：巡检日报输出

## 目标

把“今日库存反馈巡检结果”整理成便于晨会、站会、值班查看的摘要。

## 推荐输出结构

### 1. 今日反馈概览

- 总反馈数
- 与库存业务相关的反馈数
- 疑似紧急反馈数

### 2. 重点问题 TopN

每条包含：

- feedbackId
- 分类
- 紧急度
- 摘要
- 是否建议升级 Case

### 3. 暂不升级项

- 说明为什么先不升级
- 缺什么信息

### 4. 人工下一步

- 谁需要补证据
- 哪些反馈需要继续观察
- 哪些反馈建议立即审核为 Case

## 注意

- 日报是结论输出，不要重新展开全部推理过程
- 优先突出“今天最值得关注的库存风险”

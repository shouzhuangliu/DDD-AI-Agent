# 阶段 03：紧急度评估

## 目标

判断库存反馈是否属于紧急问题，是否需要优先进入 Case 升级判断。

## 紧急度分级

- `P0`：大面积下单失败、明显超卖、核心链路不可用
- `P1`：高频缺货、库存不一致已影响转化或投诉升级
- `P2`：单商品、单仓、单渠道问题，可人工兜底
- `P3`：低频反馈、信息不足、暂未验证

## 评估维度

1. 影响范围
   - 单商品 / 多商品 / 多仓 / 全站
2. 影响链路
   - 浏览、下单、支付、履约、售后
3. 用户影响
   - 只是咨询，还是已经造成下单失败 / 投诉 / 退款
4. 可恢复性
   - 是否可以靠补货、刷新、重试临时恢复

## 强提醒

以下情况优先认为至少 `P1`：

- 多个反馈指向同一库存异常
- 已出现“能下单但实际无货”
- 已出现订单库存未扣减
- 运营或客服明确指出今日集中爆发

## 何时进入下一步

当你已经给出紧急度与依据，且认为值得进入 Case 升级判断时，进入 `04-case-promotion.md`

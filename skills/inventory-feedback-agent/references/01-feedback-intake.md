# 阶段 01：拉取今日 Feedback

## 目标

拿到“今天发生了什么库存相关反馈”的原始列表，不在这个阶段直接判断是否升级 Case。

## 必做动作

1. 调用 `get_today_feedback`
2. 如果用户指定了关键词，再补调 `search_feedback_by_keyword`
3. 返回反馈清单时，至少展示：
   - feedbackId
   - 来源
   - 服务
   - 摘要
   - 发生时间
   - 当前 triage 状态

## 输出要求

- 只陈述事实，不先做复杂推理
- 如果明显与库存无关，要标记“疑似非库存问题”
- 如果摘要过短，提示后续需要读取详情

## 何时进入下一步

当你已经拿到今日反馈列表，并识别出可能与库存业务相关的项后，进入 `02-inventory-classification.md`
